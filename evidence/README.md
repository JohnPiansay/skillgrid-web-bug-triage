# Reproduction Evidence

Store screenshots and sanitized console/network exports here. Use a defect-specific filename, for example `DEF-001-keyboard-trap.png` or `DEF-002-request-failure.txt`, and link it from the corresponding report.

Capture evidence while reproducing the behavior in the staging environment. Do not add illustrative or fabricated evidence in place of a real capture.

Before committing, redact passwords, access tokens, session cookies, personal data, and other secrets. Include the page/route, browser, and capture context in the report. Avoid committing large or unrelated files.
